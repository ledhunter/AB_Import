Контекст задачи

Что нужно было сделать

▸ Цель

Автоматизировать загрузку данных о помещениях (квартирах, кладовых, машино-местах, нежилых) из Excel-файлов в систему Visary.

▸ Особенности предметной области

  • Формат Excel
  • Каждый файл содержит несколько разделов (Квартиры / Нежилые / Кладовые / Машино-места)
  • В файлах встречаются служебные листы, скрытые листы, итоговые строки — их нужно отличать от полезных данных
  • Один и тот же файл может загружаться повторно — система не должна создавать дубликаты
  • Все изменения должны корректно отражаться в системе Visary
  • Пользователь должен видеть понятный отчёт: что создано, что обновлено, что пропущено, где ошибка

03 / 09

Что получит бизнес

Ценность сервиса в пяти направлениях

🚀 Скорость

  • Загрузка файла с ~300 строками — около 1 минуты
  • Раньше тот же объём — 4 файла за 5 минут

🛡 Надёжность

  • Не создаёт дубликаты при повторной загрузке
  • Восстанавливает данные, если их удалили вручную в Visary
  • Сама разбирается с нестандартной структурой файла

📂 Универсальность

  • Понимает файлы разной структуры
  • Определяет, где квартиры, где кладовые, где машино-места
  • Игнорирует скрытые и служебные листы

👀 Прозрачность

  • По каждой строке файла: создано / обновлено / пропущено / ошибка
  • Причина ошибки на понятном языке
  • История загрузок выгружается в PDF

💰 Экономия

  • На загрузку — 1 минута вместо 5 (тот же объём)
  • Не нужен технический специалист для импорта
  • Снижается риск ошибок ручного ввода
